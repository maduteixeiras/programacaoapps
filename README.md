## COMANDOS BÁSICOS

1.Trazendo possíveis mudanças do GitHub:
git pull (git pull inicinando para analisar possíveis mudanças caso mais de uma pessoa esteja ultilizando o mesmo repositorio, evitando conflitos.)

2.Adicionar arquivos para commit:
git add . 

3.Criara versionamento (commit):
git commit -m "comandos basicos do git."

4.Enviar alterações para GitHub:
git push
